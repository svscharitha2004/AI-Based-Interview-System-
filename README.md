AI-Based Interview System 
• Objective: Develop an AI-powered interview system using Speech Recognition, NLP, and Machine Learning to assess 
candidates fairly and efficiently. 
• Technologies Used: Python, TensorFlow, NLTK, OpenAI Whisper (Speech-to-Text), Scikit-learn. 
• Features: Real-time speech analysis, automated question generation, sentiment & tone analysis, and bias-free evaluation. 
• Scoring System: Assesses technical skills (accuracy, problem-solving) and soft skills (communication, confidence, tone). 
• Outcome: Standardized, unbiased interview process with AI-driven insights for better hiring decisions.
